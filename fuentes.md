# Recursos para investigar cómo implementar git

## Fuentes en las que basarse y poder programar

<https://deepwiki.com/build-your-own-x/git-rust/1-overview>

Este link es de un weon que se dejó de tarea hacerse un clon de Git en rust,
donde el RoadMap se lo hizo con IA pero su Repositorio no tiene nada xddddd.
Anyways, es hasta ahora el más completo que me ha servido para entender el
funcionamiento de Git y sus estructuras de datos.

<https://coderefinery.github.io/git-intro/under-the-hood/>

Un link donde provee imágenes de cómo funcionan las estructuras de Git.

<https://www.geeksforgeeks.org/git/how-git-works-under-the-hood/>

El GfG siempre confiable para poder entender.

<https://www.freecodecamp.org/news/git-under-the-hood/>

Un blog que explica las funcionalidades avanzadas de Git con el merge, el
rebase y también el stash incluso.

<https://medium.com/@jorodragon/git-under-the-hood-a-deep-dive-into-how-git-really-works-150acb1e192a>

Otro blog donde se puede entender Git.

<https://app.codecrafters.io/courses/git/overview>

Es un ejercicio en una página web, donde se el pone el desafío a la gente de
implementar aplicaciones populares desde 0 en el lenguaje que quieran. No he
visto cómo lo hace, porque necesita cuenta, pero es muy interesante.

<https://medium.com/@papa90papa/how-git-works-under-the-hood-660775838624>

Otro blog donde explica como hacerlo.

<https://mahmudul.dev/posts/how-git-works-under-the-hood#what-a-commit-contains>

Parece ser un blog mucho más completo de como funciona Git, pero parece muy IA
honestamente, asi que no creo que sea confiable más que para saber términos.

## Ideas para poder diferenciarnos de la competencia

Sé que existe una manera visual de poder usar Git con una aplicación de Github.
Pero, no conozco aplicaciones que lo hagan como un TUI. Y además que sea más
intuitivo o que al menos explique lo que vas haciendo. Muchas apps asumen
que sabes Git, y te dejan con un gran repertorio de herramientas para usarlo,
pero no sabes que hace cada cosa, y peor aún, no sabes como revertirlo.

Esa podría ser una idea, hacer un TUI más amigable para nuevos usuarios de Git,
pero que también pueda escalar para usuarios avanzados idealmente (muy en el
futuro si).
